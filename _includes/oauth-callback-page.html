Code

The Copy button copies code=…&state=… in one line. The second button opens on this computer and hands the same values to AICtrlNet directly; if AICtrlNet is not running here, nothing happens and you can still copy the values above.

What this page does with the code. It reads the code and state from the address bar in your browser and shows them to you. It does not send them anywhere, loads nothing from any other website, and removes them from the address bar as soon as it has read them, so they are not kept in your browser history. The one place they still exist is the access log of the server that served this page. That is acceptable: an authorization code is single-use, expires within minutes, and is useless without the client secret, which is held only on the practice computer and never on this page.
