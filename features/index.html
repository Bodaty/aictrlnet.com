Features

Features built for the layer above the AI stack.

Humans-as-peer agents, framework cascade, three-layer integration reach, governance attached at design time. Production today, MIT-licensed.

Core architecture

Humans-as-peer agents.

Your team registers in the workflow alongside AI — capacity-routed, capability-matched, handoffs with context. Approval nodes, review queues, and escalation paths are built into the engine, not bolted on.

Approval nodes
Require human sign-off at any point in a workflow before proceeding.
Review queues
Route AI outputs to the right reviewer with priority and assignment rules.
Escalation paths
Define fallback chains when approvals aren’t granted or deadlines pass.
Human task assignment
Assign tasks based on role, expertise, capacity, or availability.
Timeout & fallback
Configurable timeouts with automatic escalation or alternative handling.
AI capabilities

Multi-framework agents with context-preserving cascade.

Bring your own framework. AICtrlNet integrates with five major AI agent frameworks — and when one fails, the next picks up state and continues.

5 framework cascade
LangChain, AutoGPT, CrewAI, AutoGen, Semantic Kernel. State preserved across switches.
43 role-configured agent templates
CEO, CFO, CMO, Sales, HR, Legal, Compliance, plus operational roles. Each with persona, behavioral rules, and workflow associations.
Custom agent creation
Build your own agents with the Python SDK or the visual builder.
Pod formation
Multi-agent collaboration within a single workflow with 5 formation strategies + 5 swarm intelligence algorithms.
Self-extending
Agents research APIs and generate adapters live. Any system becomes a tool — in minutes.

Visual builder
Drag-and-drop interface for building workflows without writing code.
183 workflow templates

Conditional logic
Branching, loops, and conditional execution based on data or human decisions.
Error handling & retry
Configurable error handling, retry policies, and dead-letter queues.
Entry points

Six channels, file upload, browser — one engine.

6 messaging channels
WhatsApp, Telegram, SMS, Slack, Discord, Email — trigger workflows from any channel.
File processing
Upload PDF, Excel, CSV, DOCX. Extract data, trigger workflows, generate documents.
Browser automation
Navigate, click, fill, extract, screenshot. The universal fallback for legacy systems.
Cross-channel conversations
One conversation spans WhatsApp + Slack + Email. Same context, any channel.

Connect

Three layers of integration reach.

Three open agent protocols spoken natively. 29 native adapters plus runtime adapter generation plus browser automation. No integration ceiling.

Salesforce HubSpot Slack Discord WhatsApp Telegram Email PostgreSQL MongoDB S3 OpenAI Anthropic n8n Zapier + runtime adapter generation
Google A2A v0.2.5
Agent-to-Agent protocol for cross-platform agent communication.
MCP (client + server)
Model Context Protocol — standardized AI tool access. 193 MCP tools across the platform.
OpenClaw Runtime Gateway
Govern external agent runtimes — even ones we didn’t build — with bidirectional NAT-safe SDKs.
Platform bridges
n8n, Zapier, Copilot, Make as nodes inside your workflows. Not rip-and-replace.
Trust journey

Governance attached at design time.

Quality, Governance, Security, and Monitoring metadata attaches at workflow creation across all 8 creation paths — not just runtime. Audit trail, risk scoring, compliance frameworks built in.

Audit trails
Complete record of every decision, approval, and AI action across workflows.
5-layer security gateway
Prompt injection detection, rate limiting, risk scoring, output validation, audit.
Risk scoring
LOW / MED / HIGH / CRITICAL ML-powered scoring on every action.
Compliance frameworks
Built-in support for SOC2, HIPAA, GDPR, ISO 25012 data quality dimensions.
Develop

Developer experience, open core.

Python SDK, REST API, CLI tools, Docker-first deployment. Build locally, deploy anywhere — your infrastructure or our managed cloud.

# Install and run
$ docker pull bodaty/aictrlnet-community
$ docker run -p 8000:8000 bodaty/aictrlnet-community

# Or use the Python SDK
$ pip install aictrlnet
$ aictrlnet init my-project
